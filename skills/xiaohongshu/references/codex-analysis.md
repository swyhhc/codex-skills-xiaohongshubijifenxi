# Codex分析契约

读取 `model-batches` 生成的每个JSON文件，只输出JSON数组。每条记录严格包含 `analysis-contract.json` 的全部字段，不增加Markdown。

## 判断要求

- 只依据标题、正文、评论、官方字幕、按顺序的图片OCR和可用本地图片。
- 采集失败时，策略字段写“无法判断”，并在 `evidence_gap` 说明缺失证据。
- 无官方字幕的视频不得猜测口播、画面顺序、首次露出时间或植入前后内容。
- `content_type` 只选一个合同允许值；按内容主结构判断，不按话题词判断。
- `commercial_judgment` 只选合同允许值。明确合作、强推广、导流或围绕单一产品完整演示可判商业/疑似商业；仅提及品牌不等于商业。
- `placement` 按“铺垫→首次出现→后续展开”写；图文注明页码，视频只有字幕证据时注明字幕线索，证据不足必须直说。
- `high_read_method` 总结可复制的方法，并引用本篇真实钩子、结构或互动机制，不写空泛结论。
- `comment_focus` 优先总结高赞评论的共同需求、争议和问题；样本不足时留空并说明。
- `cover_ocr` 以第1张图片OCR为准，可清理明显识别噪声，但不可补写看不到的字。

分析完所有批次后，先运行 `validate-analysis`；校验通过才能生成Excel。
