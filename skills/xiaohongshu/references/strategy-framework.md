# 内容DNA与策略闭环

用于批量复盘、高低效对比和完整策略分析。开始前先回答经营三问：本次分析要解决什么经营问题、用什么数据判断、结论将指导什么动作。答案不清时先向用户确认，不能用宏大框架替代真实需求。

## 六段闭环

1. Collect：读取正文、封面、素材、评论、作者与效果数据，标记缺口。
2. Decode：拆解人群、需求、情绪、场景、钩子、结构、信任证据、产品植入和行动路径。
3. Pattern：寻找重复出现且能解释效果差异的组合，不把单篇现象叫规律。
4. Strategy：把规律转成可执行动作，说明适用条件和不适用条件。
5. Predict：只有存在可比的跨期数据时才判断趋势；否则写“当前信号”。
6. Asset：沉淀可复用的人群、买点、场景、钩子、结构、反对理由和证据素材。

## 价值翻译

按“产品事实 → 用户需求 → 情绪收益 → 使用场景 → 内容资产”检查内容是否完成翻译。不要把成分或参数直接当成用户买点。

## 证据门槛

- 事实必须能回到原笔记、评论、素材或用户数据。
- 判断要写清证据和推理，不把相关性说成因果。
- 建议必须同时连接经营目标与已确认规律。
- 样本少、数据缺失或指标口径不一致时，降低置信度并明确说明。
- “规律”原则上需要多篇重复证据；样本不足时称为“线索”。
