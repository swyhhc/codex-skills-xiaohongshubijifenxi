# 投放节奏与素材规格

用于比较不同投放天数、内容形式、封面标题、达人类型、互动表现、素材规格和报价。

## 分析顺序

1. 按投放天数或阶段分组，记录每组真实样本量。
2. 比较图文、视频等内容形式及其适配的场景和信息密度。
3. 拆解封面、标题、开头、产品露出、证明方式和互动设计。
4. 结合达人角色与效果指标解释差异，不能只做排行榜。
5. 输出阶段性规律、异常样本和下一轮可验证动作。

## 约束

- 投放天数不等于内容发布时间；以用户数据字段定义为准。
- 截图未显示粉丝量、报价或完整指标时，写“未确认”，不得估算达人量级。
- 报价、规格比例和发布要求只能从当前数据计算或引用，不使用旧项目固定值。
- 固定九段式、HTML报告或其他版式仅在用户需要该交付物时使用，不作为默认输出。
