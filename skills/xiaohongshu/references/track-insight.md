# 赛道、人群与买点

用于赛道洞察、目标人群拆解和买点提炼。

## 五步定位漏斗

1. 赛道：用户实际在解决哪类问题，而不是只看产品所属品类。
2. 人群：谁在什么状态下最需要解决这个问题。
3. 场景：需求在哪个具体时刻发生。
4. 障碍：用户为什么迟迟不买、换品或相信。
5. 买点：什么利益和证据能推动下一步行动。

人群不能只写年龄和性别，应包含身份或状态、具体困扰、触发场景、购买动机和主要顾虑。买点写成用户能感知的收益，并标注支撑它的产品事实或内容证据。

## 三类决策模式

- 信任型：重视达人可信度、长期记录、他人验证和风险消除。
- 体验型：重视即时感受、过程展示、前后变化和场景代入。
- 理性型：重视机制、参数、对比、价格和使用成本。

三类模式是分析视角，不是固定行业结论。应根据当前样本判断主次。
